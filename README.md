# card108 - Đêm Giữa Hạ (Midsommar) Frontend

Tài nguyên frontend và giao diện Việt hóa cho thẻ nhân vật SillyTavern **Đêm Giữa Hạ 1.0 (Midsommar)**.

## Cấu trúc nội dung

- `dist/midsommar-style.js`: Script giao diện toàn cục, điều khiển kiểu dáng các khung cảnh, buổi trong ngày, sự kiện lớn và tùy chọn.
- `dist/midsommar-footer.js`: Thanh tiện ích cuối tầng (Lịch trình đại tiệc, Bản đồ làng Hårga, Câu chuyện của họ).
- `dist/midsommar-intro.js`: Bảng giới thiệu mở đầu, hướng dẫn cách chơi và video giới thiệu.
- `dist/midsommar-choices.js`: Thanh tùy chọn hành động cho nhân vật.
- `assets/`: Hình ảnh minh họa địa điểm, bản đồ, phong tục tập quán, sự kiện lớn và chân dung các nhân vật nữ.
